# design-vocabulary

Short notes on design vocabulary, one concept per note, linked to each other.

## Where to start

- [polish-ui](notes/polish-ui.md): the vocabulary needed to understand the [polish-ui skill](https://github.com/staticaland/skills/tree/main/plugins/polish-ui)
- [Impeccable](notes/impeccable.md): steering words from [Impeccable](https://github.com/pbakaus/impeccable), such as bolder, quieter, and distill

## How the notes work

- All notes live flat in [`notes/`](notes/). There are no folders or categories; structure comes from links.
- One concept per note. The file name is the term in kebab-case.
- Each note opens with a one-sentence definition, explains the concept in a few short paragraphs, and ends with a `Related` list.
- Links are ordinary relative Markdown links, so they work on GitHub and in most editors.
- Most notes are concepts (nouns). Some are steering words (verbs or adjectives) for directing a design, and open by saying so.
- Entry-point notes such as `polish-ui.md` hold no concept of their own. They map a source or topic to the notes that explain it.
