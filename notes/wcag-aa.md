# WCAG AA

The middle conformance level of the Web Content Accessibility Guidelines, and the one most laws and organisations require.

WCAG is the W3C's standard for accessible web content. Its requirements ("success criteria") are graded A, AA, or AAA, from the minimum to the strictest.

For [[contrast]], AA means:

| What | Minimum ratio |
| --- | --- |
| Normal text | 4.5:1 |
| Large text (about 24px and up, or about 19px and up if bold) | 3:1 |
| UI components and meaningful graphics, such as input borders and icons | 3:1 |

Disabled controls, pure decoration, and logos are exempt. AAA raises the text thresholds to 7:1 and 4.5:1.

Browser developer tools show the ratio for any text element, so it can be checked without calculating by hand.
