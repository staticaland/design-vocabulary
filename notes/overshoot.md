# Overshoot

The small amount by which round and pointed letters extend past the [[baseline]] and the [[x-height]] or [[cap-height|cap height]], so that they look the same height as flat letters.

A curve touches a line at a single point, while a flat edge sits along it. If an `o` were drawn exactly as tall as an `x`, it would look smaller. Type designers correct for this by letting the `o` dip slightly below the baseline and rise slightly above the x-height. The same is done for pointed shapes, such as the top of `A` and the bottom of `v`.

It is [[optical-alignment|optical alignment]] built into the font: the letters are made unequal so that they look equal.

Two practical consequences:

- Measure a font on flat letters such as `x`, `z`, and `H`. Round letters give a number that is a little too large.
- The same correction applies to icons and shapes. A circle beside a square of the same size looks smaller, and is drawn slightly larger to match.
