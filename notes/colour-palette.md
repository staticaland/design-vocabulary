# Colour palette

The limited set of colours a design uses.

A typical UI palette has:

- **Neutrals:** a range of greys for text, backgrounds, and borders. Most of any interface.
- **An [[accent-colour|accent colour]]:** the brand or action colour.
- **Semantic colours:** colours with a fixed meaning, commonly red for error or danger, green for success, and yellow or orange for warning.

"Limited" is the point. Each extra colour is one more thing a user has to interpret, and colours that are almost the same (four similar greys picked by eye) are the colour version of an off-[[grid]] value.

A palette is only useful if each colour has a job and keeps it. If blue means "clickable" in one place, blue decoration elsewhere misleads.
