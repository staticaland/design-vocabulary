# Truncation

Cutting content short when it does not fit, usually marked with an ellipsis (…).

Truncation keeps a layout stable at the cost of hiding information, so it suits content that is secondary or recoverable: a file name in a list where the full name appears on hover or on the detail page. It is a poor fit for content the user must read in full, such as an error message.

Truncating "cleanly" means the cut is deliberate: an ellipsis rather than text sliced mid-letter, on a whole line rather than half of one, with the full text available somewhere.

Variants: single-line truncation, multi-line truncation (line clamping), and middle truncation, which keeps both ends of a string (`report-fin…2026.pdf`).
