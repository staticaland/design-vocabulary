# Card

A rectangular container, set apart by a border, background, or shadow, that holds one self-contained unit of content.

A card is [[common-region|common region]] made into a component. It works well for a collection of similar, separate things (products, articles, projects) where each is a unit a user might act on.

Cards are overused. Wrapping every section of a page in a card adds borders and [[padding]] without adding any grouping that spacing and a heading would not already give. When everything is a card, the card no longer marks anything out.
