# Type scale

A short, fixed list of font sizes that all text in a design is chosen from.

For example: 12, 14, 16, 20, 24, 32. Many scales are built by multiplying a base size (usually the body size, often 16px) by a constant ratio, which is called a modular scale. Others are picked by hand. Either way, the steps are far enough apart to be told apart.

In a design system each step usually comes with a matching [[line-height|line height]] and [[font-weight|font weight]], and is named by role (`body`, `heading-lg`) instead of by number, so the same role looks the same everywhere.

It is the typographic counterpart of the [[spacing-scale|spacing scale]], and helps for the same reasons: fewer decisions, and differences that are visible and intended.
