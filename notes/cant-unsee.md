# Can't Unsee

A browser game that trains the eye for interface details: [cantunsee.space](https://cantunsee.space/).

Each round shows two versions of the same piece of UI, and the player picks the more correct one. The differences are small: an icon slightly off centre, uneven [[padding]], text with too little [[contrast]], a misaligned [[baseline]]. The rounds get harder as the game goes on.

It is useful because [[visual-polish|visual polish]] is first a matter of seeing. A fault has to be noticed before it can be named or fixed, and noticing improves with practice. The title is the point: after learning to see a two-pixel misalignment, it is hard to stop seeing it.

The game gives the practice but not the words. The notes here go the other way, so the two work well together.
