# Affordance

What an object lets a person do with it. In interface design, the word usually means the visible cues that show how an element can be used.

The term comes from the psychologist James Gibson, and was brought into design by Don Norman in *The Design of Everyday Things*. A handle affords pulling. A flat plate on a door affords pushing. When the cue and the action disagree, people pull a door that must be pushed.

Norman later separated two ideas that the word had merged:

- **Affordance:** the action that is possible. A button can be pressed whether or not it looks like it.
- **Signifier:** the cue that tells the user so. The button's fill, border, or label.

Everyday design talk still says "affordance" for both. "This button lacks affordance" means that nothing shows it can be clicked.

On a screen nothing has a physical form, so every cue has to be drawn. Common ones are a filled or bordered shape for buttons, colour and underline for links, a sunken box for text fields, and a change on hover or focus. The cues work by convention and [[similarity]]: users know what a button looks like from every other button they have met.

The typical failures:

- **Missing cue:** an interactive element that looks like plain text or decoration, so it is never found.
- **False cue:** something that looks interactive and is not, such as static text in the link colour or a [[card]] that looks clickable.
