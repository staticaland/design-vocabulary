# Similarity

The [[gestalt-principles|Gestalt principle]] that elements which look alike are perceived as related, or as doing the same job.

Colour, shape, size, and style all count. Colour is usually the strongest. Unlike [[proximity]] and [[common-region|common region]], similarity works across distance: every link on a page can share one colour and be understood as the same kind of thing, wherever it sits.

This makes similarity the principle behind consistency. If all buttons look like buttons, a user learns the pattern once and can apply it everywhere. It cuts both ways:

- **Things that do the same job must look the same.** Two styles for one kind of action make users wonder what the difference means.
- **Things that do different jobs must not look the same.** Text in the [[accent-colour|accent colour]] that is not a link will be clicked. A destructive action styled like a harmless one will be pressed by mistake.

Breaking similarity on purpose is a form of [[emphasis]]. One item that differs from its neighbours draws the eye, which is how a primary button stands out in a row of secondary ones.
