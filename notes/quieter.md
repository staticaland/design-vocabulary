# Quieter

A [[steering-words|steering word]]: asking for a design to be made less intense, so that it is calmer and easier on the eyes.

It is the answer to a design that shouts: too many saturated colours, heavy elements competing with each other, motion everywhere. Quieter turns the intensity down. It does not remove content, which is [[distill|distilling]].

The sources of loudness, and the matching moves:

- **Colour:** lower the saturation, use fewer colours, and let neutrals carry most of the surface, with the [[accent-colour]] kept for a few places.
- **Weight:** lighter [[font-weight|font weights]], thinner or no borders, fewer filled shapes. See [[visual-weight]].
- **Space:** more room between elements and lower density.
- **Decoration:** fewer shadows, gradients, and glows.
- **Motion:** shorter, gentler animation, kept only where it tells the user something.

Quiet is not the same as generic. The failure is grey text on white, one weight throughout, and a grid of identical cards: nothing is loud, and nothing is anything. A quiet design still needs [[visual-hierarchy|hierarchy]] and a few strong anchors. This makes it harder than loud design, because with less ink on the page each remaining difference has to be exact.

What "quieter" means depends on the kind of page. On a marketing page it means restraint, with the character kept. In a tool that people work in all day it means the interface getting out of the way of the task.
