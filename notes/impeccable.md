# Impeccable (source map)

An entry point, not a concept. It maps commands from [Impeccable](https://github.com/pbakaus/impeccable), a design skill for coding agents, to the notes that explain them.

Impeccable's vocabulary is mostly verbs: words for telling an agent which way to push a design. The notes cover the idea behind each word, which is useful with or without the tool.

| Command | Note |
| --- | --- |
| `bolder` | [Bolder](bolder.md) |
| `quieter` | [Quieter](quieter.md) |
| `distill` | [Distill](distill.md) |

Only these three are covered so far.
