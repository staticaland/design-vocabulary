# Impeccable (source map)

An entry point, not a concept. It maps commands from [Impeccable](https://github.com/pbakaus/impeccable), a design skill for coding agents, to the notes that explain them.

Impeccable's vocabulary is mostly [[steering-words|steering words]]: words for telling an agent which way to push a design. The notes cover the idea behind each word, which is useful with or without the tool.

- `bolder`: [[bolder|Bolder]]
- `quieter`: [[quieter|Quieter]]
- `distill`: [[distill|Distill]]

Only these three are covered so far.
