# Gestalt principles

A set of observations from early twentieth-century psychology about how people perceive separate visual elements as organised groups and wholes.

The core idea is that perception groups things automatically, before any conscious reading. A designer cannot switch this off, only use it or fight it. If two unrelated things look grouped, users will assume they are related.

The principles most used in UI design:

- **[[proximity|Proximity]]:** things close together are seen as a group.
- **[[common-region|Common region]]:** things inside the same boundary are seen as a group.
- **[[similarity|Similarity]]:** things that look alike (colour, shape, size) are seen as related.
- **Continuity:** things on a line or curve are seen as belonging together. This is why [[alignment]] groups.
