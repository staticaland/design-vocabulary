# Bolder

A [[steering-words|steering word]]: asking for a design, or one part of it, to be made more confident and striking.

It is the answer to a design that is correct but flat, where nothing is wrong and nothing is memorable. The request is nearly always about one part of something that already exists, such as a hero section or a pricing table, so the rest of the page stays as it is.

Bolder does not mean more of everything. Adding gradients, shadows, and extra colours is the reflex, and it produces noise. If every element gets louder, the result is flatter, for the same reason that [[emphasis]] fails when everything is emphasised.

What works:

- **Amplify what is already there.** Use the existing [[type-scale|type scale]] at its largest step and the existing [[accent-colour|accent colour]] with more conviction, instead of bringing in new fonts or colours. The result should look more like the same brand, not like a different one.
- **Make one decisive move, fully.** One very large heading, or one strong block of colour. A half-measure reads as a mistake.
- **Quiet the surroundings.** The move is only visible against calm neighbours.

A useful check is to imagine the section without its words. If the structure alone no longer shows what matters, the boldness was only in the text size.
