# Quartz

A free, open-source tool that turns a folder of Markdown notes into a website: [quartz.jzhao.xyz](https://quartz.jzhao.xyz/).

It describes itself as "a fast, batteries-included static-site generator". It is made by Jacky Zhao, and it is the usual way to publish an Obsidian vault without paying for hosting. It reads Obsidian's `[[link]]` syntax directly and can deploy to GitHub Pages.

Its features are close to a list of what a notes site needs: a graph view, backlinks, previews when hovering over a link, and full-text search.

This collection's site is hand-built and does a subset of the same things. That keeps it small and fully under control, at the cost of maintaining the code. Because the notes already use Obsidian's syntax, moving to Quartz later would not mean rewriting them.
