# Grid

A set of predefined lines that elements are placed on, so that positions and sizes come from a system instead of being chosen one by one.

Two kinds matter for UI work:

- **Layout grid:** columns and gutters that divide the page width (a 12-column grid is common). Elements span whole columns.
- **Spacing grid:** a base unit, often 4px or 8px, that every size and distance is a multiple of. See [spacing scale](spacing-scale.md).

**Off-grid** means an element sits at a position or size the system does not produce: 13px where everything else is 12 or 16. Off-grid values are usually accidents, such as a one-off tweak or a border that added an unaccounted pixel.
